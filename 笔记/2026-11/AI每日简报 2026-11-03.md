**🧠 Agent / 工具 — WebHarbor: Docking Real Websites for Evolving GUI Agent Environments**
把真实网站「停靠」成可持续演化的 GUI Agent 训练/评测环境。做 Agent 评测的人可以直接借这套思路解决「环境会漂移」的老问题。

### 💡 小编建议

1. **把「规则兜底」当成 Agent 落地的默认架构**：novel-config-copilot 的 60%→100% 合法率、以及 DeepSeek/清华系近期几篇 Agent 工程文，都在说同一件事——生成式负责覆盖率，确定性代码负责红线。你手上的用户运营场景（发券、人群圈选、触达频控）恰好是「错一次就有成本」的类型，可以先在两三个硬约束上试试这个分层。
2. **今天最值得读的一篇是 WebHarbor**：如果你的 Agent 评测还在用固定测试集，环境漂移会让结论快速过期；「把真实站点 dock 成可演化环境」是更可持续的做法。
