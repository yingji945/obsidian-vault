## 表结构详解

### 1. 券配置域

#### COUPON_PLAN（券方案）

| 字段 | 类型 | 键 | 说明 |
|:----|:----|:--|:----|
| id | bigint | PK | 主键 |
| plan_no | string | UK | 方案编号 |
| plan_status | tinyint | — | 方案状态 |

> 与 COUPON_TEMPLATE 为 **1:N** 关系（通过 PLAN_TEMPLATE_REL 关联）

#### COUPON_TEMPLATE（券模板）

| 字段 | 类型 | 键 | 说明 |
|:----|:----|:--|:----|
| id | bigint | PK | 主键 |
| template_no | string | UK | 模板编号 |
| denomination | decimal | — | **面额** |
| validity_type | tinyint | — | **有效期类型**（如领取后N天/固定日期） |

> 被 ACTIVITY_PRIZE 引用，**定义现金红包奖品**

#### PLAN_TEMPLATE_REL（方案模板关联表）

> 券方案与券模板的 N:N 关联表

---

### 2. 活动配置域（核心）

#### ACTIVITY（活动）

| 字段 | 类型 | 键 | 说明 |
|:----|:----|:--|:----|
| id | bigint | PK | 主键 |
| activity_no | string | UK | 活动编号 |
| activity_start_time | datetime | — | 活动开始时间 |
| activity_end_time | datetime | — | 活动结束时间 |
| is_expand | tinyint | — | **是否含膨胀** |

> **核心枢纽表**，向下关联 8 张子表

#### ACTIVITY_PRIZE（活动奖品配置）

| 字段 | 类型 | 键 | 说明 |
|:----|:----|:--|:----|
| id | bigint | PK | 主键 |
| activity_id | bigint | FK | 活动 ID |
| redpack_coupon_template_id | bigint | FK | **现金红包券模板 ID**（引用 COUPON_TEMPLATE） |
| mall_coupon_template_id | bigint | — | **外部商城券 ID**（膨胀券场景） |
| is_expand | tinyint | — | **是否膨胀**：0=现金 1=膨胀券 |
| expand_multiple | decimal | — | **膨胀倍数**（如 2 倍） |

> 关联 USER_RECORD_LINE → **确定中奖行**

#### ACTIVITY_COMMODITY（活动适用商品）

> 配置活动适用的商品范围（图中未展开）

#### ACTIVITY_TIME_BUCKET（活动分时段限量）

> 按时间段分配奖品库存（图中未展开）

#### ACTIVITY_CITY（活动限定城市）

> 按城市限定活动范围（图中未展开）

---

### 3. 日志域

#### PARTICIPATE_LOG（参与日志）

| 字段 | 类型 | 键 | 说明 |
|:----|:----|:--|:----|
| id | bigint | PK | 主键 |
| scan_id | string | — | **扫码 ID** |
| participate_phase | tinyint | — | **首扫/复扫** |
| layer_break_code | tinyint | — | **拦截层级**（记录在第几级拦截失败） |

> ⚠️ **关键埋点表**：layer_break_code 记录了用户在哪级拦截失败，可用于分析漏斗转化

#### INVENTORY_LEDGER（库存变更流水）

> 库存增减的流水记录（图中未展开）

---

### 4. 用户中奖域

#### USER_RECORD_LINE（用户中奖记录行）

| 字段 | 类型 | 键 | 说明 |
|:----|:----|:--|:----|
| id | bigint | PK | 主键 |
| activity_id | bigint | FK | 活动 ID |
| member_id | bigint | — | 会员 ID |
| first_scan_id | string | UK | **首扫幂等键**（防重复中奖） |
| record_prize_status | tinyint | — | **待选/发放/膨胀**（对应状态机 10~30） |
| user_instance_id | bigint | FK | **关联现金实例**（选现金路径时引用） |

> 与 USER_INSTANCE 的关系：**1:1**（仅当用户选现金红包路径）

#### USER_INSTANCE（现金发放实例）

| 字段 | 类型 | 键 | 说明 |
|:----|:----|:--|:----|
| id | bigint | PK | 主键 |
| activity_id | bigint | FK | 活动 ID |
| member_id | bigint | — | 会员 ID |
| instance_status | smallint | — | **LOCKING / PAYING / DONE**（对应状态机 20/40/50） |
| first_scan_id | string | UK | 首扫幂等键 |
| pay_retry_count | int | — | **打款重试次数**（对应 40→20 回退计数） |

> ⚠️ `pay_retry_count` 字段直接对应流程图中的 **40→20 支付失败重试**逻辑

## 关系汇总

| 表 A | 关系 | 表 B | 说明 |
|:----|:----|:----|:------|
| COUPON_PLAN | 1:N → | PLAN_TEMPLATE_REL | 一个券方案包含多个模板关联 |
| COUPON_TEMPLATE | 1:N → | PLAN_TEMPLATE_REL | 一个券模板可被多个方案引用 |
| COUPON_TEMPLATE | 1:N → | ACTIVITY_PRIZE | 券模板定义奖品 |
| ACTIVITY | 1:N → | ACTIVITY_PRIZE | 一个活动多个奖品配置 |
| ACTIVITY | 1:N → | ACTIVITY_COMMODITY | 活动适用商品 |
| ACTIVITY | 1:N → | ACTIVITY_TIME_BUCKET | 分时段限量 |
| ACTIVITY | 1:N → | ACTIVITY_CITY | 限定城市 |
| ACTIVITY | 1:N → | PARTICIPATE_LOG | 扫码记录 |
| ACTIVITY | 1:N → | INVENTORY_LEDGER | 库存变更 |
| ACTIVITY | 1:N → | USER_RECORD_LINE | 中奖记录 |
| ACTIVITY | 1:N → | USER_INSTANCE | 现金发放 |
| ACTIVITY_PRIZE | 1:N → | USER_RECORD_LINE | 奖品格子 → 用户中奖行 |
| USER_RECORD_LINE | 1:1 → | USER_INSTANCE | 中奖记录 → 现金实例（仅现金路径） |

## 关联说明

| 数据域 | 表 | 关联关系 |
|:------|:---|:--------|
| **数据字典**（ODS/DWD/DWS/ADS） | 13 张分析表 | 与领域模型互补：领域模型管业务写入，数据字典管分析读取 |
| **状态机** | USER_RECORD_LINE.record_prize_status + USER_INSTANCE.instance_status | 对应 02-码生命周期设计 中的 8 状态流转 |
| **流程图** | PARTICIPATE_LOG.layer_break_code + USER_INSTANCE.pay_retry_count | 对应 03-系统交互矩阵 中的拦截和重试 |
