## 一、双头人总框架

**双头人** = 带着一线手感拍板的人（隐性端 × 判断端焊在同一人身上）。练法总纲：**手感靠保鲜，判断靠记账，桥靠翻译**。

| 头 | 训练本质 | 一句话原则 |
|:--|:--|:--|
| 隐性端（手感） | 保鲜 + 校准 | 手感是「亲自触碰」的频率，不是资历 |
| 判断端（拍板） | 记账 + 延迟反馈 | 拍板不留痕，等于没拍过 |
| 桥（翻译层） | 协议化 | 手感报警，数据审判，判断终审——顺序不能乱 |

### 1.1 隐性端：保鲜 + 校准

手感的最大敌人是**过期**——三个月不碰一线，「直觉」就开始替你脑补。两件事：

1. **每周固定「手活时间」（不可谈判）**：手工跑一遍核心指标 SQL（不看现成 dashboard——dashboard 是别人嚼过的）；读 N 条原始用户原话/客诉（不看汇总）；翻几条没整理过的一线记录。升职以后这条最难守住：**判断离开手感三天，就开始自说自话**；
2. **体感日志 + 命中率账本**：随时记「说不清但觉得不对」的瞬间（捕获模糊感是可以练的肌肉）；每次体感出门前变成可证伪预测（「我赌沉默人群转化下周掉 0.3pp」），月底对账命中率。**命中率显著高于瞎猜的那部分，才是可信手感；剩下的只是焦虑。**

### 1.2 判断端：记账 + 延迟反馈

判断力的反馈周期最长（一个决定几周才知道对错），所以大多数人拍了一辈子板判断力纹丝不动。解法是人为造反馈回路：

- **决策日志五栏**：日期 / 决定 / 当时知道什么 / 为什么选它（排除过哪些选项）/ 预期 30 天后会怎样；
- **30/90 天延迟回看**，打分标准是「在当时信息下是不是好决策」——**判断力 = 好决策率，不是好结果率**（结果有运气）；
- **预 mortem**：重大决定前强制写三条「6 个月后这个决定被证明是错的，最可能因为____」，然后逐一去堵；
- **主动接「难而小」的判断**：判断肌肉要渐进超负荷——在没人替你拍板的场合先自己扛（三省六部里主动当议题 owner，而不是永远当协调者）。

### 1.3 桥（翻译层）：协议化

体感要升级成判断之前，走一遍**三栏说明书**：

1. **我感觉到什么**——允许不理性，记身体信号（哪场会坐立不安、哪个数据看了不舒服）；
2. **为什么可能对**——至少给三个候选机制解释；
3. **哪个能用数据验证**——设计验证，交给数据审判。

**冲突协议**：体感和数据打架时，不许默认信任何一边，只问两个问题——「指标是不是在测错的东西？」（体感可能对，指标没捕捉到）「我的体感是不是过期经验？」（数据可能对，世界变了）。冲突本身是信号，结论写进复盘。

### 1.4 落地节奏

| 频率 | 动作 |
|:--|:--|
| 每周 | 手活时间 + 体感日志过一遍 |
| 每次拍板 | 决策日志（重大决定加预 mortem） |
| 30/90 天 | 决策回看打分 |
| 每月 | 体感命中率对账 |
| 每季 | 判断审计——让 AI 当反方质询你的体感（「如果这个直觉是错的，最可能因为什么」） |

**最小可行版**：只先跑「决策日志 30 天」——三块里唯一带延迟反馈的训练，一条顶三条。

> 金句：经验 × 反馈 = 专家；经验 × 零反馈 = 老油条。

## 二、翻译机制与移植报告练法

### 2.1 翻译三层（为什么翻译 ≠ 类比）

类比停在表面，翻译三层落地：

1. **结构层**：两个领域的问题结构是否同构（热机吸热→做功→排热 ≈ 流量进入→产生价值→必然流失）；
2. **语言层**：换成目标领域的术语、约束、行话；
3. **实现层**：变成目标领域里可操作的动作。

**失真风险 → 假设标注**：借来的概念会偷渡源领域的隐藏假设——物理「熵」借到管理学变成玄学流行词，就因为没人标注「孤立系统/微观态」没跟过来。写清哪些假设留下了、哪些没跟过来，是防「炫耀性引喻」的保险丝。

**成功判据**：目标领域的人说「这说的就是我们的事」，而不是「好深奥啊」——翻成行话，不是展示深奥。

### 2.2 移植报告练法（可训练格式）

拿母语领域一个概念写三栏：**①结构是什么 ②对应目标领域的什么 ③哪些假设不成立**。写三份，翻译肌肉成型。

**实战样例：热力学 × 用户运营**（2026-09-06）：

| 源概念 | 目标概念 | 同构 |
|:--|:--|:--:|
| 高温热源吸热→做功→低温排热 | 流量进入→产生价值→必然流失 | ★★★ |
| 热效率 η = W/Q₁ | 转化效率 = 产出价值 / 总投入流量 | ★★★ |
| 卡诺极限（天花板由温差决定） | 转化天花板由「产品×人群需求温差」决定 | ★★ |
| 不可逆损失（每级压降/散热） | 每环节流失 | ★★★ |
| 火用（能量有品质） | 流量有温度（高意向 vs 泛流量） | ★★★ |
| 热泵逆循环（1 份功搬 3-5 份热） | 唤醒沉默用户（低品位热源回收） | ★★★ |

**四个可检验推论**：
1. **先问温差，再抠漏斗**——转化率低，先看是不是在给低温热源（泛流量）做引擎优化；人群分层 = 给流量测温分质；
2. **堵最大的火用损失**——算「每环节损失率 × 该环节流量价值」，排序后只优化第一项（一条 SQL 能跑出来）；
3. **热泵唤醒存量**——唤醒 ROI vs 拉新 ROI 决定预算挪移；且沉默越久温差越大、泵效越低 → 沉睡分级 + 浅睡期唤醒（沉睡预警 = 趁温差还小的时候开泵）；
4. **相变潜热**——用户激活不是线性升温，是相变：累积触达/价值认知是潜热（温度不变、状态在变），越过相变点才跳升。若触达频次 vs 激活率是台阶式，就别用平均触达成本做预算，要找相变点。

**本例的假设标注**（没跟过来的）：天花板可变（运营能「加热源」，热机工程师改不了 T₁/T₂）；流量不守恒（推荐/口碑是正反馈，热机不会自己多吸热）；工质不耗竭但用户会疲劳（触达疲劳不在模型里）；流失可测不可全归因。

## 三、能力清单三件套

| 能力 | 缺了它怎么死 | 可教性 | 最小练法 |
|:--|:--|:--|:--|
| 深度锚点（至少一门母语级手艺） | 桥没墩，浅跨界 | 可教 | 费曼测试：无资料讲透 + 被追问不露怯 |
| 翻译 | 炫耀性引喻，伪跨界 | 可教 | 移植报告 ×3 |
| 时机感 | 烈士：太早 = 与错无异 | 半可教（只能真实下注 + 延迟复盘） | 记录时机判断 + 回看命中 |

> 锚点是本金，翻译是复利能力，时机是卖出点。自己的配置：**双母语 = 工科思维算子（守恒/效率/熵/流动）+ 运营手艺与 SQL**。
> 有钱不会配置是守财奴（深井专家），会配置没钱是空谈家（浅跨界），两者俱全但择时全错，就是历史里没人记得的巴贝奇。

**时机感的精确机制**（为什么它是「半可教」）：
- 定义：**爆发点 = 新排列成本曲线降到旧方案之下、且体验不降的那一刻**。之前都是布道，之后才是收割；
- 四个可设计动作：**在场**（泡在领域里，窗口开时够得着）/ **就绪**（锚点与翻译练好，能立刻焊）/ **小注**（期权思维：同时跟踪多个交叉点、低成本试探，买「连接可成时我在场且有资格」）/ **止损**（承认太早，离场等下一班）；
- 最难教的原因：模拟出来的时机判断全是假的，**反馈只能来自真实世界**——必须真实下注、延迟复盘、记命中率。

## 四、翻译是漏斗（闸门训练）

五级漏斗：**海量候选概念 → 同构检验（死得最多）→ 语言转译 → 可操作化 → 数据验证**。被记住的跨界连接是漏斗幸存者（又一次幸存者偏差）。

推论：
1. **翻译能力不在漏斗口（点子多），在闸门（杀得快）**——高手 90% 的候选概念在结构层就毙了；恋爱脑（爱上自己的比喻硬推过闸）是伪跨界者死因；
2. **漏斗不是翻译的形状，是万物的形状**——自然选择/风投/销售全是同一形状；翻译只是「生成-筛选」系统的一个实例。**排列负责生成（爆炸式），漏斗负责筛选（收敛式）**——跨界、进化、市场是同一个循环。

> 金句：灵光负责进料，闸门负责出货——跨界者的手艺不在上游的灵感，在下游的枪毙。

## 五、与团队框架的双向性

- **横向翻译** = 跨界创新（把 A 领域概念搬进 B 领域）；**纵向翻译** = 组织协调（给数分说 SQL 口径、给运营说用户指标、给老板说 ROI）——同一块肌肉：协调者 = 纵向往返的翻译者，跨界者 = 横向搬运的翻译者（机制版见 [[超级个体到超级团队-协调者生长框架]] 附录十一 11.3）；
