## 📄 重点论文

| 分类 | 论文 | 链接 |
|:--|:--|:--|
| 🧠 Agent / 工具 | Pack Light, CarryOn: Building Object-Oriented Context for Long-Horizon Agents | [arXiv](https://arxiv.org/abs/2610.18784) |
| 🧠 Agent / 工具 | Self-Evolving Agent Harness | [arXiv](https://arxiv.org/abs/2610.18813) |
| 🦾 具身智能 | Who Improves the Robot? Toward Physical Recursive Self-Improvement | [arXiv](https://arxiv.org/abs/2610.18842) |
| 🧠 Agent / 工具 | AesCode: Aesthetic Code Generation with Decoupled Cross-Modal Rewards | [arXiv](https://arxiv.org/abs/2610.18860) |
| 🤖 LLM / 基础模型 | Read the Room Before Your Model Generates | [arXiv](https://arxiv.org/abs/2610.18820) |
| 🔬 AI for Science | MFG: Multi-turn Feedback Guided Molecular Optimization | [arXiv](https://arxiv.org/abs/2610.18851) |

**看点：**
- **Pack Light, CarryOn（面向长程 Agent 的「面向对象」上下文）**：把上下文按对象组织、按需携带，直击长程 Agent 的上下文膨胀问题。和今天 APUS 的「无限上下文」是同一命题的**学术解法 vs 工程解法**——你做 Agent 时如果上下文开始变贵，这篇的抽象方式可以直接借鉴。
- **Self-Evolving Agent Harness**：让 Agent 的「外壳」（工具编排、流程骨架）自我演进，而不是只优化 prompt。这是 RSI 在 Agent 工程侧的落点。
- **Who Improves the Robot? 走向物理递归自我改进**：RSI 从模型/代码扩到**机器人自我改进**，呼应 10-05 Hinton 首篇 RSI 论文那条主线——RSI 正在从「显学」变成多模态多形态的通用议题。
- **Read the Room Before Your Model Generates**：生成前先「读场」——本质是**受众/场景建模**。这条对做用户触达的人最直白：同一句话发给不同人群，效果差异来自「读场」，不来自文案本身。
- **AesCode（审美代码生成）**：用解耦的跨模态奖励让生成的代码/界面「好看」——奖励解耦的设计思路可迁移到任何「既要功能对、又要观感好」的生成任务（如权益页、活动页物料）。
