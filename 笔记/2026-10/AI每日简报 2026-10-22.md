### 📄 重点论文

🧠 **Agent / 工具（+ 数据分析，推荐给运营岗）** — [Charts as Epistemic Actions for Experience-Driven Agentic Data Analysis](https://arxiv.org/abs/2610.30072)
把「画图」从结果展示重新定义为 Agent 的**认知动作**——图表是 Agent 用来探索数据结构、发现异常的手段，而非最后交付物。对做日常经营分析、想让 Agent 自己跑数的人来说，这篇的框架比模型选型更有用。

🧠 **Agent / 工具** — [HGM-Dual: Lineage-Aware Guided Agent Harness Optimization for Long-Horizon Planning](https://arxiv.org/abs/2610.30042)
用「血缘（lineage）感知」来优化 Agent 骨架，专攻长程规划——多步任务里哪一步的策略该被继承、哪一步该被丢弃，是当前 Agent 工程最脏的活。

🧠 **Agent / 工具** — [GuideEvolve: Self-Evolving Agent Framework with Expert Guidance and 3Ts Mechanisms](https://arxiv.org/abs/2610.30017)
自演进 Agent，靠专家引导 + 3Ts 机制自我迭代。RSI 主线在 Agent 层的又一次落点（今年 9 月以来第 N 篇，已属显学）。

🧠 **Agent / 工具** — [TIDE: Tree-Induced Fine-Grained Diagnostic Evaluation from Model Behaviors](https://arxiv.org/abs/2610.29985)
从行为轨迹反推树状诊断，把「模型为什么错」细粒度地归因到具体步骤。评估从打分走向诊断，是今年评测类论文的共同方向。

🧠 **Agent / 工具** — [Robust Soft Skill Adaptation via Behavioral Localization in Tool-Using Agents](https://arxiv.org/abs/2610.30041)
工具型 Agent 的「软技能」（何时该问、何时该停、怎么措辞）如何稳定迁移。软技能比硬工具调用更影响真实体验。

🔬 **方法论 / 决策模型评估** — [Which Differences Matter? Controlled Tests of Rule Transfer, Joint Reliability, and Information Use in Decision Models](https://arxiv.org/abs/2610.30045)
受控实验拆解决策模型的三件事：规则能否迁移、联合可靠性、信息是否真被用上。「看起来会用信息」和「真的用了」之间差距很大。

### 💡 小编建议

1. **今天最值得读的是第一篇论文，不是融资新闻。** 「Charts as Epistemic Actions」跟你每天做的事高度重合——如果下一步要在 Hermes 里搭「自主跑数」的 Agent，难点不是 SQL，而是让 Agent 知道「该画什么图来验证自己的假设」。可以拿它对照一下你现在报表链路的假设检验方式。
2. **今日 arXiv 6 篇里 5 篇是 Agent，且集中在评估/自演进。** 说明这个赛道已经从「能不能做」进入「怎么证明做对了」。你如果要做 AB 实验或 Agent 效果评估，TIDE 的「行为树诊断」思路比传统漏斗归因更细，值得扫一眼摘要。
