# 认知演进模型：认知如何像人一样成长

> 这是知识库的生长规律——解释「为什么知识库这样设计、内容为什么这样迁移」。
> 操作规则见 [[知识库整理规范]] 第七章；存储架构见 [[四层记忆架构与AI记忆方案一览]]。

---

## 一、核心类比

> **认知的成长 = 人的成长：碎片 → 混着长 → 器官分化 → 系统成熟。**

胚胎期所有细胞混在一起长；器官成熟后分化出独立功能；器官多了按系统分组；最后长成可独立行动的能力。知识库里的认知走的是同一条路。

## 二、四阶段模型

| 阶段 | 载体 | 性质 | 类比 |
|:----|:----|:----|:----|
| ① 认知碎片 | 对话、memory 便签 | 尚未成型，一闪而过 | 受精卵 |
| ② 演进日记 | `关于我（持续构建）.md` | 轨迹，混着长 | 胚胎期 |
| ③ 观点库/方法论 | 独立文件（我的AI观、判断标准…） | 现状，器官分化 | 器官 |
| ④ 技能化 | skill（可复用流程 + 坑位积累） | 肌肉记忆 | 成熟能力 |

一条认知走完 ①→④，就是一次完整的「生长」。

## 三、每个阶段的「长大信号」

| 阶段迁移 | 信号 | 阈值 |
|:--------|:----|:----|
| ②→③ 抽离成文件 | 主题在演进日记重复 / 篇幅失衡 | ≥3 次，或占全文 >1/3 |
| ③→④ 技能化 | 方法被反复使用、值得流程化 | 2-3 次复用 |
| ④ 的进化 | skill 坑位持续积累 | 坑21-23 就是例子 |

## 四、与四层记忆架构的关系

| 层 | 角色 | 对应阶段 |
|:--|:----|:--------|
| Memory | 随身便签（碎片暂存） | ① |
| Vault | 私人图书馆（①②③的容器） | ②③ |
| Skill | 肌肉记忆（④） | ④ |

## 五、怎么用这个模型

每次讨论后问自己：**这条认知现在在哪一层？**

- 还在对话里 → 重大认知就双写进演进日记
- 已在演进日记重复出现 → 该抽离成独立文件
- 方法被反复用 → 该沉淀为 skill
- 目录长到阈值 → 该分簇整理

## 六、实例：一条完整生长链（2026-08-02）

「三省六部 = 理想决策结构投射」的完整旅程：

```
① 对话碎片（7月聊制度设计）
  → ② 演进日记（第四次更新记录认知）
  → ③ 独立方法论（governance-frameworks.md）
  → ④ 技能化（御史台·红队大臣上线，坑21-23 积累）
```

这就是这篇模型存在的意义：**让每一次生长都有据可依，而不是凭感觉决定往哪放。**

## 七、三观框架：个人成长的自然结构（2026-08-02）

2026-08-02 用户发现：个人成长的文档在不经意间长成了「三观」的形状——因为知识库是认知的外化，而人的认知天然分三观。

| 观 | 定义 | 对应文档 | 成熟度 |
|----|------|---------|--------|
| 🌍 **世界观** | 对世界/社会/技术如何运转的看法 | 人口结构与社会适应、我的AI观、我的体系观 | ✅ 清晰 |
| 🧭 **人生观** | 人怎么活、怎么成长、成为什么 | 关于我×2、认知演进模型、我的哲学底色 | ✅ 清晰（2026-08-31 补齐） |
| 💎 **价值观** | 判断好坏对错的标准 | 我的判断标准 | ✅ 清晰 |
| 🛠️ **知识库系统**（元层） | 关于知识库本身，不属于三观 | 四层记忆架构、Obsidian同步、首页、整理规范 | — |

> 📌 **体系观**（2026-08-03 新增）：世界观之下关于「体系/结构/系统如何运转」的子主题，已独立成文 → [[我的体系观]]（制度·结构·系统思维）

### 两个推论

1. **将来分簇优先按三观语义分**：世界观 / 人生观 / 价值观 / 知识库系统 四簇，比功能性分法更有意义（规范第七章已同步）
2. **三观 = 认知体检表**：能照出薄弱维度——「人生观」曾是薄弱维度，2026-08-31 哲学底色独立成文（→ [[人生观/我的哲学底色|我的哲学底色]]）后已补齐 ✅。**规则：以后聊哲学时，人生观维度单独养**（已兑现，归入人生观簇）。**路径固定：哲学内容直接追加至 [[人生观/我的哲学底色|我的哲学底色]]，不进演进日记**（演进日记只记重大自我认知变化）
