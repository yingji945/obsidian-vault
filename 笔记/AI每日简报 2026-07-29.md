### 📄 重点论文（2026年7月29日）

**🔒 安全对齐 — Shieldstral（Mistral / FAIR 联合出品）**
3B 参数的多模态安全分类器，在文本安全基准上匹配或超越近 7 倍规模的模型，在多模态安全分类上达到 SOTA。
🔗 https://arxiv.org/abs/2607.25857

**🧠 Agent / 工具 — Speculate While You Reason（Joint Agent-Speculator RL）**
提出一种通过联合强化学习训练 Agent 和 Speculator 的新方法，让 Agent 在推理过程中就能预测并预执行下一个工具调用，大幅减少等待工具返回的延迟。
🔗 https://arxiv.org/abs/2607.25816

**🤖 LLM / 基础模型 — Penelope: Localized Latent Recurrence for Efficient Structured Reasoning**
一种高效的潜空间推理方法，在不依赖 CoT 长序列的前提下，通过局部潜循环实现结构化推理，显著降低推理成本。
🔗 https://arxiv.org/abs/2607.25915

**🧠 Agent / 工具 — Desktop-Delta Bench：桌面 GUI 智能体评测新基准**
评测计算机使用模型（CUA）能否理解桌面 GUI 状态之间的因果转换，而不仅仅是最终任务成功率。
🔗 https://arxiv.org/abs/2607.26041

**🧠 Agent / 工具 — UniMem：面向边界无关任务流的互补记忆架构**
为 LLM Agent 设计的记忆系统，融合情景记忆和参数记忆，解决稳定性-可塑性的两难问题。
🔗 https://arxiv.org/abs/2607.26017

**🧠 Agent / 工具 — Messier：跨基准 Agent 评估的高分辨率语料库**
提出了一个用于跨基准评估 LLM Agent 的高质量语料库，帮助标准化 Agent 能力评测。
🔗 https://arxiv.org/abs/2607.25891

**🤖 LLM / 基础模型 — Pass the Baton：轨迹中继在线蒸馏**
提出一种新颖的轨迹中继在线蒸馏方法，让轻量模型通过接力学习大模型的推理轨迹。
🔗 https://arxiv.org/abs/2607.26057

**👁️ 多模态 — 多轮多模态诊断推理评估（Rui Yang 等 25 位作者）**
在真实临床病例上评估大模型的多轮多模态诊断推理能力，覆盖大规模国际合作团队。
🔗 https://arxiv.org/abs/2607.25933

### 💡 小编建议

1. **关注 Shieldstral**：Mistral/FAIR 联合出品的 3B 多模态安全分类器，表明小参数模型在安全领域的潜力巨大，适合做边缘部署或辅助审核系统。

2. **Agent 推理加速是热点**：今天 arXiv 同时出现至少 3 篇与 Agent 工具调用加速/推理优化相关的论文（Speculate While You Reason、Penelope、AngelSpec），说明业界正在从“模型能做”转向“模型做得快”。如果你的产品用到了 Agent + Tool Calling，值得跟进这一方向。
