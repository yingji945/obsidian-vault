# 02-码生命周期设计

> 从码生成到核销/失效的完整状态流转
>
> 📌 2026-07-28 初版：基于后端技术方案 + Jacob复盘整理

---

## 码的体系

一物一码项目涉及 **五码体系**（对接易全系统）：

| 码类型 | 位置 | 用途 |
|:------|:-----|:-----|
| **瓶内码** | 瓶盖内部 | 活动参与入口，扫码抽奖 |
| **瓶盖外码** | 瓶盖外部 | 消费者溯源 + "欢迎扫瓶内码"引导 |
| **瓶身码** | 瓶身 | 活动规则说明入口 |
| **箱内码** | 包装箱内 | 渠道管理 |
| **箱外码** | 包装箱外 | 物流追踪 |
| **垛码** | 托盘 | 仓储管理 |

---

## 码状态流转

```
易全生成（未激活）
  ↓
印刷到瓶身（已分配）
  ↓
产品出厂（已激活）
  ↓
用户扫码
  ├── ✅ 有效 → 校验通过 → 参与活动 → 状态变更为"已使用"
  ├── ❌ 无效 → 码不存在或已作废
  └── 🔄 已使用 → 重复扫码提示
```

### 关键校验

| 校验点 | 调用方 | 说明 |
|:------|:-------|:-----|
| 码有效性 | 易全五码系统 | 接口返回：有效/无效/已使用 |
| 码状态同步 | 电商促销系统→易全 | 用户扫码后异步同步状态 |

---

## 扫码场景

| 场景 | 触发方式 | 说明 |
|:----|:--------|:-----|
| **首扫码（活动）** | 瓶盖内码 | 用户首次发现并扫码参与活动 |
| **复购扫码** | 第二瓶瓶盖内码 | 已中奖用户购买第二瓶后扫码履约 |
| **规则扫码** | 瓶身码 | 用户扫码查看活动规则 |
| **溯源扫码** | 瓶盖外码 | 生产溯源信息 |

---

## 关联关系

| 实体 | 关联说明 |
|:----|:---------|
| 首扫码 ID | 记录用户首次中奖的扫码记录 |
| 预生成权益 ID | 首扫码时预生成待履约的权益 |
| 复购码 ID | 第二瓶扫码的码记录 |
| 微信商户单号 | 现金红包打款的交易凭证 |
