### 📄 重点论文

1. 🧠 **Can Mechanistic Interpretability Help Explain LLM Agent Failures? A Case Study on Web Element Hallucination**
   用机制可解释性方法定位"Web Agent 点错元素"的失败根因。**这篇是今日最值得读的**：它把 Agent 失败从"结果指标"下沉到"内部表征"，为 Agent 评测提供了可归因的分析路径。
   https://arxiv.org/abs/2611.18514

2. 🧠 **ModHarness-RL: Recasting Harnesses as Learnable and Evolving Programs for Agentic RL**
   把 Agent Harness（提示词+工具编排+重试逻辑那套脚手架）从人手写改为**可学习、可演化**的程序，用 RL 训练。与 11-07「Agent Harness 抢跑」同一趋势线，说明"脚手架本身成为被优化对象"。
   https://arxiv.org/abs/2611.18533

3. 🔒 **Alignment by Socialization: Learning Tradeoffs Under Selection**
   提出"社会化对齐"：不靠单一目标函数，而让模型在选择压力下学习多目标权衡。方向接近 11-03 讨论的权重级干预，但走的是训练动力学路线。
   https://arxiv.org/abs/2611.18531

4. 🧠 **Imitation Bootstrapped Multi-Agent Reinforcement Learning**
   用模仿引导多智能体 RL 的冷启动，缓解多 Agent 协作训练初期的稀疏奖励问题。
   https://arxiv.org/abs/2611.18543

5. 🤖 **ARCHER: From Rationale Imitation to Executable Reasoning in Small Language Models**
   小模型不再只模仿推理链文本，而是把 rationale 转成可执行步骤——对小参数量模型做数据分析/取数类任务是直接可借鉴的思路。
   https://arxiv.org/abs/2611.18494

6. 🔬 **Typing Matters: Muscle, Language and Typing Behaviour in Live Keystroke Decoding from sEMG**
   sEMG 实时击键解码，加入语言先验后准确率显著提升。属人机接口/生物信号交叉方向。
   https://arxiv.org/abs/2611.18464
