## 码的体系

一物一码项目涉及 **五码体系**（对接易全系统）：

| 码类型 | 位置 | 用途 |
|:------|:-----|:-----|
| **瓶内码** | 瓶盖内部 | 活动参与入口，扫码抽奖 |
| **瓶盖外码** | 瓶盖外部 | 消费者溯源 + "欢迎扫瓶内码"引导 |
| **瓶身码** | 瓶身 | 活动规则说明入口 |
| **箱内码** | 包装箱内 | 渠道管理 |
| **箱外码** | 包装箱外 | 物流追踪 |
| **垛码** | 托盘 | 仓储管理 |

## 红包权益状态机（完整版）

> 📌 基于 2026-07-29 文档补充：V26.4.1 技术方案中的 8 状态模型

### 状态总表

| 状态码 | 状态名称（英文） | 业务场景 | 关联数据 | 终态 |
|:-----|:---------------|:--------|:--------|:----|
| **10** | 待选择 (INIT) | 用户首扫中奖，尚未点击"领红包"或"去膨胀" | 首扫码 ID | ❌ |
| **20** | 待复购 (LOCKING) | 用户选择了现金，权益被锁定，等待购买第二瓶 | 首扫码、预生成权益 ID | ❌ |
| **30** | 待使用 (ACTIVE) | 用户选择了膨胀券，券已发至券包，可直接下单 | 商城优惠券 ID | ❌ |
| **40** | 打款中 (PAYING) | 用户完成复购扫码，系统正在请求微信支付接口 | 复购码 ID、微信商户单号 | ❌ |
| **50** | 已到账 (TRANSFERRED) | **【终态1】** 现金成功发放至用户微信零钱 | 微信支付流水号、打款时间 | ✅ |
| **60** | 已使用 (CONSUMED) | **【终态2】** 用户在商城下单并成功抵扣了膨胀券 | 商城订单号、父订单编号 | ✅ |
| **70** | 已过期 (EXPIRED) | 超过复购限时或商城券有效期 | — | ✅ |
| **80** | 已失效 (INVALIDATED) | 发生退货逆向、风控拦截或活动配置变更作废 | 失效原因说明 | ✅ |

### 完整流转图

```
        首扫中奖
            │
         10 待选择 (INIT)
          / \
   选现金/   \选膨胀券
        /     \
  20 待复购  30 待使用 (ACTIVE)
  (LOCKING)    │
       │       ├── 商城下单 → 60 已使用 (CONSUMED) ✅
       │       ├── 过期    → 70 已过期 (EXPIRED) ✅
       │       └── 逆向    → 80 已失效 (INVALIDATED) ✅
       │
   购买第2瓶 → 复购扫码
       │
  40 打款中 (PAYING)
       │
  50 已到账 (TRANSFERRED) ✅
       └── 也可经逆向 → 80 已失效
```

### 状态流转说明

| 流转路径 | 触发条件 | 说明 |
|:--------|:--------|:----|
| 10 → 20 | 用户选择"领现金" | 预生成权益 ID，锁定现金红包 |
| 10 → 30 | 用户选择"去膨胀" | 发放膨胀券到券包 |
| 20 → 40 | 用户扫码第二瓶（复购码） | 关联首扫码 + 复购码，请求微信支付 |
| 30 → 60 | 用户在商城使用膨胀券下单 | 更新状态，绑定商城订单号和父订单编号 |
| 40 → 50 | 微信支付返回成功 | **终态1**：现金到账 |
| — → 70 | 超过有效期 | 各阶段超时均可能触发过期 |
| — → 80 | 退货/风控/配置变更 | 非正常终止，需记录失效原因 |

## 码本身状态（易全侧）

```
易全生成（未激活）
  ↓
印刷到瓶身（已分配）
  ↓
产品出厂（已激活）
  ↓
用户扫码
  ├── ✅ 有效 → 校验通过 → 参与活动
  ├── ❌ 无效 → 码不存在或已作废
  └── 🔄 已使用 → 重复扫码提示
```

---

## 关键校验

| 校验点 | 调用方 | 说明 |
|:------|:-------|:-----|
| 码有效性 | 易全五码系统 | 接口返回：有效/无效/已使用 |
| 码状态同步 | 电商促销系统→易全 | 用户扫码后异步同步状态 |

## 扫码场景

| 场景 | 触发方式 | 说明 |
|:----|:--------|:-----|
| **首扫码（活动）** | 瓶盖内码 | 用户首次发现并扫码参与活动 |
| **复购扫码** | 第二瓶瓶盖内码 | 已中奖用户购买第二瓶后扫码履约 |
| **规则扫码** | 瓶身码 | 用户扫码查看活动规则 |
| **溯源扫码** | 瓶盖外码 | 生产溯源信息 |
