# 09-运营后台配置流程

> 📌 基于 V26.6.2 项目流程图 + 原型图整理（2026-07-29）
>
> 运营人员在后台配置瓶内营销活动的完整操作流程

## 活动配置总流程

```
进入活动配置页面
    ↓
① 活动基本信息配置
    ↓
② 上传图片配置 → 可点击问号查看效果示意图
    ↓
③ 奖品配置（普通/膨胀）
    ↓
④ 流程规则说明（可收起/展开）
    ↓
保存配置 → 配置完成 ✅
```

---

## ① 活动基本信息配置

**原型图：** 活动基本信息配置页

| 字段 | 类型 | 必填 | 说明 |
|:----|:----|:----|:----|
| 活动编号 | 只读文本 | — | 系统生成，如 `ACT_HB_20260615803` |
| 活动名称 | 文本输入 | ✅ | 如"复购红包 · 3月档" |
| 活动背景竖图 | 文件上传 | — | 用户端竖屏背景，1080x1920，支持 png/jpg/gif/webp |
| 活动背景横图 | 文件上传 | — | 用户端横屏/宽屏背景，1920x1080，同上 |
| 背景色 | 颜色选择器 | — | 可点击"重置"恢复默认 |
| 抽奖动效 | 文件上传 | — | 抽奖过程动效，支持 gif/webp/mp4，≤5MB |
| 活动场景 | 只读 | — | 固定"瓶内营销" |
| 瓶身码跳转链接 | URL 输入 | — | 用户扫瓶身码后的跳转地址 |
| 活动开始时间 | 日期时间选择器 | ✅ | 与结束时间同行展示，格式 yyyy/MM/dd HH:mm |
| 活动结束时间 | 日期时间选择器 | ✅ | 同上 |
| 活动规则说明 | 多行文本 | ✅ | 展示在 C 端活动页，支持换行 |

> ⚠️ 图片配置项右侧有 **蓝色问号图标** → 点击弹出该图片在用户端的实际展示位置示意图

## ② 奖品配置

**原型图：** 奖品信息配置页

### 奖品基本信息

| 字段 | 类型 | 必填 | 说明 |
|:----|:----|:----|:----|
| 奖品名称 | 文本输入 | ✅ | 展示给用户 |
| 奖品大图 | 文件上传 | ✅ | 500x500，支持 png/jpg/gif/webp |
| 奖品发放方式 | 下拉选择 | ✅ | **加私域获得** / 直接获得 |
| 加私域图片 | 文件上传 | ⚠️ | **选「加私域获得」时必传**，1125x1275 |
| 奖品剩余数量 | 只读文本 | — | 按活动实际自动回写 |
| 奖品实际概率 | 只读文本 | — | 按中奖次数/参与次数自动回写 |
| 是否默认奖项 | 开关 | ✅ | 是/否（切换选择） |
| 重复获得 | 开关 | ✅ | 是/否（同一用户可多次获得） |

### 券配置

| 字段 | 类型 | 必填 | 说明 |
|:----|:----|:----|:----|
| 奖品类型 | 下拉选择 | ✅ | — |
| 券类型 | 下拉选择 | ✅ | 如"即享优惠券" |
| 券方案编号 | 文本输入 + 查询按钮 | ✅ | 输入后点"查询"校验 |
| 方案发放次数 | 数字输入 | ✅ | 发放数量 = 券方案模板数量 × 发放次数 |

### 奖品流程规则说明

> 可展开/收起，内设"领取前"和"领取后"两段文案编辑器

| 子模块 | 字段 | 说明 |
|:------|:----|:----|
| **领取前** | 标题 | 如"恭喜获得抽奖机会" |
| | 正文 | 多段可添加（+添加正文按钮），渲染为有序列表 |
| **领取后** | 标题 | 如"奖品已发放至券包" |
| | 正文 | 同上 |

## ③ 膨胀奖品配置

**原型图：** 膨胀奖品配置页

### 是否膨胀开关

```
[* 是否膨胀]   ○ 否    ● 是
```

选"是"时展开膨胀配置区域，选"否"时隐藏。

### 膨胀效果配置

| 字段 | 说明 |
|:----|:----|
| 奖品膨胀效果大图 | 用户端膨胀弹窗展示的图片 |
| + 添加膨胀奖品 | 蓝色按钮，点击新增一个膨胀奖品配置 |

### 多膨胀奖品管理（Tab 形式）

```
┌──────────────────────────────────────────────┐
│  膨胀奖品1  │  膨胀奖品2  │  膨胀奖品3  │     │  ← Tab 切换
└──────────────────────────────────────────────┘
```

每个 Tab 内容在一个**橙色边框卡片**内，右上角有 **「删除膨胀奖品」**（红色文字）。

### 单个膨胀奖品配置表单

| 字段 | 类型 | 必填 | 说明 |
|:----|:----|:----|:----|
| 膨胀奖品名称 | 文本输入 | ✅ | 展示给用户 |
| 膨胀奖品大图 | 文件上传 | ✅ | 每个膨胀奖品独立配图 |
| 膨胀概率 | 开关 | ✅ | **不限** 或 **限定**（选限定→显示概率输入框） |
| 奖品发放方式 | 下拉选择 | ✅ | 直接获得 / 加私域获得 |
| 券类型 | 下拉选择 | ✅ | 如"即享优惠券" |
| 券方案编码 | 文本+查询 | — | 可选 |
| 奖品流程规则说明 | 折叠区域 | — | 同上（领取前/领取后文案） |

> ⚠️ 至少保留 1 个膨胀奖品，只剩 1 个时删除按钮提示"至少保留一个膨胀奖品"

## ④ 活动记录与奖品重发

**原型图：** 活动效果详情页

### 页面结构

```
[← 返回活动记录]

活动效果详情 · ACT_HB_202603001 春季复购红包
按用户查看领取与膨胀明细
```

### 筛选栏

| 筛选条件 | 输入类型 |
|:--------|:--------|
| 用户编号 | 文本输入（如 `user_001`） |
| 用户名称 | 文本输入 |
| 奖品 | 文本输入 |
| 奖品状态 | 下拉（全部） |
| 券类型 | 下拉（全部） |
| 券状态 | 下拉（全部） |
| **[查询]** | 蓝色按钮 |
| **[重置]** | 白色按钮 |

### 奖品重发

```
可勾选一个或多个奖品后进行重发
                          [🎁 奖品重发]  ← 蓝色按钮
```

- 未选择记录→点击提示"请选择需要重发的奖品记录"
- 已选择→按钮高亮显示已选数量
- 重发前校验：已成功发放或已兑换的不再重复发放

## 二期新增的后台能力

| 功能 | 说明 |
|:----|:----|
| **奖品重发** | 活动记录页选择用户 → 点击「🎁 奖品重发」→ 系统防重复校验后重发 |
| **未中奖大图** | 奖品概率 < 100% 时，必须上传未中奖图片（保存时强制校验） |
| **效果示意图** | 图片配置项右侧问号图标 → 点击弹出该图片在用户端的实际展示位置 |
| **膨胀概率配置** | 不限 / 限定两种模式，命中奖品后二次膨胀概率 |
| **多膨胀奖品 Tab** | 支持多个膨胀奖品 Tab 切换管理 |
| **领取流程文案编辑器** | 领取前/领取后分段配置，支持多段正文有序列表 |
