### 📄 重点论文

**🧠 Agent / 工具** — [SwarmEvolve: Latent Agent Swarms for Evolutionary Discovery and Optimization](https://arxiv.org/abs/2611.08483)
把「智能体群体」放到潜空间里做进化式搜索与优化。与近月 RSI 主线（自我改进）直接接壤：从单 Agent 反思，转向群体级进化。

**🧠 Agent / 工具** — [Scientist World: Grow a Research World for AI-Scientists](https://arxiv.org/abs/2611.08478)
为「AI 科学家」造一个可生长的研究世界——把科研环境本身当成可训练/可交互的载体，是 Agent 训练环境化的又一例。

**🔬 AI for Science** — [The Gold Rush in AI4Math, II: What are signatures of AI-assisted Proofs?](https://arxiv.org/abs/2611.08412)
AI4Math 系列第二篇，试图找出「AI 参与证明」的可识别特征。对做 AI 数学评审/学术诚信的人比对新模型更有用。

**🧠 Agent / 工具** — [Benchmarks as Software: Terminal-Bench and the Case for Continuous Benchmarks](https://arxiv.org/abs/2611.08417)
主张基准应当像软件一样持续维护、持续跑（Terminal-Bench 为案例）。呼应 10-09 那篇 METR 时间跨度被统计学重新审视：Benchmark 本身要工程化。

**🔬 AI for Science** — [ReproBridge: Building Reproducibility into ML Research Artifacts](https://arxiv.org/abs/2611.08452)
把可复现性做进研究产物的构建流程里，而不是事后补。与上一篇同属「研究基础设施」簇。

**👁️ 多模态** — [The Power of Meta Access in the Software of the Future — Demonstrated on LLM Chat UIs and Chat AI](https://arxiv.org/abs/2611.08428)
以 LLM 聊天 UI 为切口谈「元访问权」：谁能以程序方式访问界面元信息，决定了下一代软件的话语权。对做 Agent 操作 GUI 的方向有直接参考价值。
