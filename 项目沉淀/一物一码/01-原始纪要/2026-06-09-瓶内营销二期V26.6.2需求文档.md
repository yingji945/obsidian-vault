# V26.6.2【即享需求】瓶内营销二期

> 📌 瓶内营销第二期需求文档，麻孜凯编写
>
> 2026-06-09 初版，2026-06-26 v1.1 修订（删除复购领取按钮）
>
> 全文 4,253 字，20 个功能点

## 核心问题（为什么做二期）

| 问题 | 描述 | 影响 |
|:----|:----|:----|
| **信息不透明** | 膨胀按钮只展示"去膨胀"文字，用户无法预知能获得什么券 | 用户决策成本高，点击意愿低 |
| **感知弱** | 用户缺乏对膨胀收益的直观预期 | 参与意愿降低 |
| **转化率低** | 上述两个问题导致 | 膨胀功能点击率待提升 |

## C 端页面变化

| 页面 | 变化 |
|:----|:----|
| **中奖结果页** | 可配置背景横图；无膨胀→奖品大图；有膨胀→膨胀效果大图；选了膨胀→膨胀奖品大图 |
| **抽奖活动页** | 展示后台配置的活动竖图；未登录弹窗任何位置点击重新弹出 |
| **中奖后需膨胀** | 展示膨胀效果大图、领取按钮、立即膨胀按钮 |
| **领取/膨胀后** | 去使用→跳转对应链接（即享券→商品列表，门店券→门店页）；**复购领取按钮已删除** |
| **复购获得 Tips** | 现金红包→"将在24小时内发到微信零钱"；优惠券→"将在24小时内发到瑞幸账户" |

## 后台新功能

| 新功能 | 说明 |
|:------|:----|
| **奖品重发** | 运营可在活动记录页选择用户，手动重发未到账的奖品（含防重发校验） |
| **膨胀概率配置** | 命中奖品后、选膨胀时，二次概率决定膨胀为哪个奖品 |
| **未中奖大图** | 当奖品中奖概率 < 100% 时必须上传未中奖图片 |

## 与 V26.4.1 的演进关系

| 维度 | V26.4.1（一期） | V26.6.2（二期） |
|:----|:--------------|:--------------|
| **膨胀体验** | 仅"去膨胀"按钮，用户盲点 | 展示膨胀效果大图 + 多奖品 Tab + 概率预览 |
| **奖品数量** | 单膨胀奖品 | 多膨胀奖品（Tab 切换） |
| **运营配置** | 基础奖品配置 | 图片配置、动效配置、效果示意图引导 |
| **复购领取按钮** | 有 | **已删除**（表明复购链路简化为直接到账） |
| **重发能力** | 无 | 运营后台可手动重发奖品 |
