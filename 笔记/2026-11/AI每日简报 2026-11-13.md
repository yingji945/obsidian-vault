### 📄 重点论文

**🧠 Agent / 工具 — CoReMem：把「记忆成本」算进连续编码任务**
*Cost-Internalizing Memory for Successive Coding Tasks with Prospective Valuation*
给每条记忆做前瞻估值：记不记取决于「未来可能省多少」。上下文预算有限的连续任务里，这套账可以直接搬到取数/分析 Agent 的记忆管理上——记忆不是越多越好，是要算投入产出。
https://arxiv.org/abs/2611.17316

**🧠 Agent / 工具 — AgentSSL：MLE Agent 能不能吃上无标注数据**
把半监督那套搬到机器学习工程 Agent 上，问的是「没有标签时 Agent 还能不能自己变强」。结论是能，但收益高度依赖任务结构。
https://arxiv.org/abs/2611.17323

**🧠 Agent / 工具 — Ballad：用 Bandit 做 LLM 路由，自动发现启发式策略**
多模型路由不靠人工规则，把「选哪个模型」变成在线学习问题。这是省 Token 最直接的一条路，和你按任务难度分配模型的做法同源，只是把经验换成了自动搜索。
https://arxiv.org/abs/2611.17241

**🤖 LLM / 基础模型 — 经典能量模型学推理，比循环模型快 1000 倍**
对「堆深度 / 堆循环次数换推理能力」的主流路线给了个反例：结构对了，速度可以差三个数量级。
https://arxiv.org/abs/2611.17309

**🧠 Agent / 工具 — LiveGeo：在持续变化的世界里评测地理 Agent**
静态基准测不出「世界变了之后 Agent 还对不对」，LiveGeo 把「环境演化」写进评测。任何依赖外部数据的 Agent 都该关心这个失效模式：指标没变、口径变了。
https://arxiv.org/abs/2611.17267

### 💡 小编建议

1. **今天两条主线其实是同一条**：Ballad（路由自动学）+ CoReMem（记忆算成本）+ MiniMax 两毛一张生图，讲的都是「别用最贵的那条路」。落到你的工作里就是两件事：简单取数走便宜模型、复杂归因走贵模型（可先手动分档、跑一周看命中率，再考虑自动化）；素材类需求优先走低价开源生图，把设计预算留给需要品牌调性的物料。
2. **璇玑那条值得单独点开**：企业语义层和你的数据字典是同一个位置的两个形态——你的数据字典是给人看的，语义层是给 Agent 看的。如果后续团队要接 AI 取数，数据字典里「口径定义 + 有效状态 + 排除条件」这些字段基本可以直接抽成语义层输入，这是现有资产最容易被低估的一次复用。
