## B. scanOutcome 枚举

**定义位置**：`com.lucky.epromotion.api.enums.rtd.RtdCapScanOutcomeEnum`

| 枚举值 | 语义 | 典型出参字段 |
|--------|------|----------------|
| `CAN_LOTTERY` | 可抽奖（盖内码首扫命中活动，或复扫同码 `hit_result=1` 且 `activity_id` 有效） | `activityBrief` + `activityStatusTag` |
| `NO_ACTIVITY` | 无可参与活动（首扫/复扫 `hit_result=0`，或 `hit_result=1` 且 `activity_id` 无效） | `fallbackTopicPageUrl` |
| `CODE_USED` | 此二维码已被使用（异会员复扫） | `codeUsedMessage` |
| `NOT_WIN` | 很遗憾本次未中奖（复扫同码 `hit_result=2` 或物化行作废） | `notWinMessage` |
| `PRIZE_PENDING` | 奖品待选择（物化行 `record_prize_status=1`） | `prizeInfo` |
| `RED_PACK_CHOSEN` | 已选/已发放红包（`record_coupon_kind=1`） | `grantedPrizeRecord` |
| `INSTANT_COUPON_CHOSEN` | 已选即享券（`record_coupon_kind=2`） | `grantedPrizeRecord` |
| `COFFEE_COUPON_CHOSEN` | 已选咖啡券（`record_coupon_kind=3`） | `grantedPrizeRecord` |
| `COFFEE_STORE_COUPON_CHOSEN` | 已选咖啡库券（`record_coupon_kind=4`） | `grantedPrizeRecord` |

**废止**：笼统 `PRIZE_CHOSEN`；抽奖侧顶层码 `AUTO_GRANT` / `MANUAL_SELECT` **不**用于扫码 `scanOutcome`。

> **规格预留**：`BODY_SCAN_REDIRECT`（瓶身码引流）见 spec Session 2026-05-18；**当前 `RtdCapScanOutcomeEnum` 未实现**，出参无 `bodyScanRedirectUrl`。
