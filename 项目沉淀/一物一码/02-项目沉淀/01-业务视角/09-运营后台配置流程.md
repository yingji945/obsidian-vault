# 09-运营后台配置流程

> 📌 基于 V26.6.2 项目流程图整理（2026-07-29）
>
> 运营人员在后台配置瓶内营销活动的完整操作流程

## 活动配置总流程

### 步骤一：活动基本信息配置

**原型图见** `2026-07-29 视觉分析 - 活动基本信息配置原型`

#### 表单字段

| 字段 | 类型 | 必填 | 说明 |
|:----|:----|:----|:----|
| 活动编号 | 只读文本 | — | 系统生成，如 `ACT_HB_20260615803` |
| 活动名称 | 文本输入 | ✅ | 如"复购红包 · 3月档" |
| 活动背景竖图 | 文件上传 | — | 用户端竖屏背景，支持 png/jpg/gif/webp |
| 活动背景横图 | 文件上传 | — | 用户端横屏/宽屏背景，同上 |
| 背景色 | 颜色选择器 | — | 可重置 |
| 抽奖动效 | 文件上传 | — | 抽奖过程动效，支持 gif/webp/mp4 |
| 活动场景 | 只读 | — | 固定"瓶内营销" |
| 瓶身码跳转链接 | URL 输入 | — | 用户扫瓶身码后的跳转地址 |
| 活动开始时间 | 日期时间选择器 | ✅ | 格式 yyyy/MM/dd HH:mm |
| 活动结束时间 | 日期时间选择器 | ✅ | 同上 |
| 活动规则说明 | 多行文本 | ✅ | 展示在 C 端活动页，支持换行 |

> ⚠️ 图片配置项右侧有 **蓝色问号图标** → 点击弹出该图片在用户端实际展示位置示意图

### 步骤二：上传图片配置

```
进入活动配置页面
    ↓
活动基本信息配置
  ├── 活动名称/时间（开始与结束同行展示）
  ├── 活动背景竖图上传（1080x1920, jpg/png）
  ├── 活动背景横图上传（1920x1080, jpg/png）
  └── 抽奖动效上传（gif/webp/mp4, ≤5MB）
    ↓
上传图片配置 → 可点击问号查看效果示意图
    ├── [查看] → 弹出效果示意图弹窗
    └── [不查看] → 继续配置
    ↓
奖品配置
  ├── 奖品大图上传（500x500, jpg/png）
  ├── 奖品剩余数量 + 实际概率同行展示
  ├── 是否默认奖项 + 重复获得开关同行展示
  └── 奖品列表支持拖动排序
    ↓
┌──── 是否膨胀奖品？
│
├── 是 → 展开膨胀奖品配置
│       ├── 奖品膨胀效果大图上传
│       ├── 膨胀奖品大图上传
│       ├── 膨胀概率配置（不限/限定）
│       ├── 添加多个膨胀奖品（Tab 管理）
│       └── 每个膨胀奖品支持删除（至少保留1个）
│
└── 否 → 普通奖品配置（无膨胀逻辑）
    ↓
流程规则说明（可收起/展开）
    ↓
保存配置
    ↓
配置完成 ✅
```

## 膨胀奖品配置细节

```
是否膨胀 = 是
    ↓
展开膨胀相关配置区域
    ↓
配置膨胀效果大图（用户侧膨胀弹窗展示的图片）
    ↓
配置膨胀奖品大图（每个膨胀奖品的展示图）
    ↓
膨胀概率配置
  ├── 不限 → 中奖后自动膨胀
  └── 限定 → 输入二次概率值（用户选膨胀时再算概率）
    ↓
添加膨胀奖品（可添加多个）
  ├── 每个膨胀奖品一个 Tab
  ├── Tab 支持点击切换预览
  └── 至少保留 1 个膨胀奖品
```

## 二期新增的后台能力

| 功能 | 说明 |
|:----|:----|
| **奖品重发** | 活动记录页选择用户 → 点击「🎁 奖品重发」→ 系统防重复校验后重发 |
| **未中奖大图** | 奖品概率 < 100% 时，必须上传未中奖图片（保存时强制校验） |
| **效果示意图** | 图片配置项右侧问号图标 → 点击弹出该图片在用户端的实际展示位置 |
| **横向优化** | 时间同行展示、概率+余量同行展示、折叠交互减少页面滚动 |
