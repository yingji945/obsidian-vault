# 05-看板健壮性检查表

> ⏳ 待复盘讨论后填充
>
> 业务系统发版或字段变更时，数据同学应该逐项检查的清单。
>
> 目标：把「看板崩了」从被动发现变成主动预防。

## 发版前检查清单

- [ ] 确认本次发版涉及的字段变更
- [ ] 对照 [[字段映射清单]] 检查受影响的数仓表
- [ ] 检查 ETL 脚本是否需要同步修改
- [ ] 检查 DWD/DWS 层依赖关系是否断裂
- [ ] 在测试环境跑一遍受影响的看板SQL
- [ ] 与预期值对比，确认无异常

## 发版后监控清单

- [ ] 观察看板数据（连续3天）
- [ ] 核对关键指标（扫码量、中奖量、红包发放量）
- [ ] 检查异常告警是否触发
- [ ] 如有异常，对照 [[断链事故记录]] 排查

## 看板自愈机制

（可选）是否可以在数仓层设字段变更的自动检测？如：
- 字段缺失检测：ODS层字段名与预期不符时告警
- 空值率突变检测：某字段空值率从1%突增到100%
- 数据量突变检测：日增量骤降或骤升
