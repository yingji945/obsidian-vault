## 📄 重点论文

1. 🤖 **LLM / 基础模型** — *RSI-Prime: Training Models to Train Models*：把"训练能力"本身作为优化目标，RSI 线（递归自我改进）再添一篇方法论工作。
   https://arxiv.org/abs/2611.23138

2. 🧠 **Agent / 工具** — *Colombo: A Frontier-to-Frontier Autoresearch System for Oracle-Based Optimization*：前沿模型对前沿模型做"自动科研"，以 Oracle 优化为落地场景。
   https://arxiv.org/abs/2611.23080

3. 🧠 **Agent / 工具** — *The Resolution Hypothesis: Agent Evolution's Key Is Identifying Improvements*：提出 Agent 进化的关键是"识别出哪些改进是真的改进"，直指自演进 Agent 的评估瓶颈。
   https://arxiv.org/abs/2611.23068

4. 🧠 **Agent / 工具** — *Agent Trust Infrastructure (ATI)*：跨组织自主 Agent 的联邦身份、信任、证明与问责架构。企业多系统/多商家对接 Agent 时的"责任边界"问题，第一次被系统性地工程化。
   https://arxiv.org/abs/2611.23202

5. 🔒 **安全对齐** — *Hidden-State Similarity Predicts Re-Elicitation After Inoculation Prompting*：用隐藏态相似度预测"免疫式提示"（inoculation prompting）后能力是否被重新诱发，给出可量化的泄漏预警信号。
   https://arxiv.org/abs/2611.23096
