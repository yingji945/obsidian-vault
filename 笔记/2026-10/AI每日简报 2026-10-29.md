## 📄 重点论文

🤖 **LLM / 基础模型** — **What Improves During Pretraining? Tracking Knowledge Acquisition with Point-in-Time Models**
用「时间切片模型」追踪预训练过程中知识是怎么被逐步学到的——回答的是「预训练到底在变强哪一块」，对判断 checkpoint 什么时候够用很实用。
[arXiv:2610.37631](https://arxiv.org/abs/2610.37631)

🧠 **Agent / 工具** — **Rare, Relevant, and Still Wrong: How Memory Fails LLM Group Decisions** ⭐ 今日最值得读
记忆在 LLM 群体决策中失效的模式：命中了、相关了，但**仍然错**。对「多 Agent 共享知识库」是直接警告——检索正确 ≠ 决策正确。
[arXiv:2610.37624](https://arxiv.org/abs/2610.37624)

🧠 **Agent / 工具** — **TeamGym: A Gym for Team Decision-Making by AI Agents with Distributed Information**
分布式信息下的多 Agent 团队决策训练环境。信息不对称是真实组织常态，这个环境补的正是「大家都只看自己那半边数据」的场景。
[arXiv:2610.37571](https://arxiv.org/abs/2610.37571)

🧠 **Agent / 工具** — **From Interaction to Capability: Task Advancement as State and Supervision for GUI Agents**
把「任务推进程度」本身当作状态与监督信号来训 GUI Agent，而不是只学下一步点哪里。
[arXiv:2610.37482](https://arxiv.org/abs/2610.37482)

🧠 **Agent / 工具** — **Concordat: Typed Sessions for LLM Agents**
给 Agent 间会话加上类型系统（typed sessions），把 Agent 通信从自由文本约束成有协议的交互。
[arXiv:2610.37461](https://arxiv.org/abs/2610.37461)

🔬 **AI for Science** — **KPPax: preprocess differentiable kinetic ODE for atmospheric chemistry**
大气化学动力学 ODE 的可微预处理，让机器学习能接进化学机理模型。工科味道最重的一篇。
[arXiv:2610.37655](https://arxiv.org/abs/2610.37655)

## 💡 小编建议

1. **今天要读的就一篇：`Rare, Relevant, and Still Wrong`**。你手上正在做 AB 实验和人群口径沉淀，这篇讲的正是「检索到了、口径也对，但结论还是错」——多 Agent 共享知识库时最隐蔽的坑，和你数据库里「先定口径再取数」的习惯是同一个问题的学术版。
2. **Agent 架构在分叉，值得记一笔**：扩散范式做 Agent 主干（35B，比 Jev 快一倍）+ 给 Agent 通信加类型系统（Concordat），一条打延迟、一条打可靠性。如果年内有第二个团队复现扩散 Agent，这就不是孤例而是新路线了——今天先存疑、别下结论。
