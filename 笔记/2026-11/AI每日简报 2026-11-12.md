### 📄 重点论文

**🧠 Agent / 工具 — 企业分析型 Agent 评测框架横向对比**
*Comparative Analysis of Agent Evaluation Frameworks: Stability, Detection, and Discovery in Enterprise Analytics Agents*
直击痛点：企业数据分析 Agent 到底该怎么评。三个维度——稳定性（同样问题重复跑是否一致）、检测力（能否发现异常）、发现力（能否挖出新洞察）。对做 BI/取数 Agent 的人是最有直接参考价值的一篇。
https://arxiv.org/abs/2611.14493

**🧠 Agent / 工具 — ReTrace：把会用工具的 Agent 蒸馏成无规划器工作流**
*ReTrace: Distilling Tool-Using Agents into Planner-Free Workflows*
思路是把「Agent 每次现场规划」的贵路径，蒸馏成固定可执行流程：保留工具调用能力，砍掉规划开销。工程上等价于「一次探索、长期复用」。
https://arxiv.org/abs/2611.14492

**🔬 AI for Science — Contrastive Discovery：用竞争性解释做开放式科学发现**
*Contrastive Discovery: Open-Ended Scientific Discovery over Competing Explanations*
不追求单一最优假设，而是让多个解释互相竞争、用证据淘汰。方法论上对「多假设并行验证」的分析工作也有借鉴。
https://arxiv.org/abs/2611.14514

**🤖 LLM / 基础模型 — Re-Search：用双人提问博弈拆解 LLM 的构思过程**
*Re-Search: Dissecting LLM Ideation Through a Two-Player Questioning Game*
把「模型怎么想出点子」拆成提问者—回答者的博弈结构来观测，是研究 ideation 过程而非结果的路子。
https://arxiv.org/abs/2611.14487

**🤖 LLM / 基础模型 — 按需精度：在不确定的解码步提升权重位宽**
*Precision on Demand: Escalating Weight Bits at Uncertain Decoding Steps in a Small Local Model*
小模型本地部署的省钱思路：大部分 token 用低位宽跑，只在模型自己「没把握」的步骤临时升精度。与「算力按需分配」是同一逻辑。
https://arxiv.org/abs/2611.14418

**🤖 LLM / 基础模型 — 评估 LLM 生成的世界模型用于神经符号推理**
*Evaluating LLM-Generated World Models for Neuro-Symbolic Reasoning*
检验 LLM 自己「脑补」出来的世界模型能否支撑符号推理，是「世界模型是否真懂因果」的一条检验路径。
https://arxiv.org/abs/2611.14419

### 💡 小编建议
