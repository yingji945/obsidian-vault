### 📰 行业新闻

🚀 **Kimi K3 正式开源：2.8T 参数的多模态 Agent 模型，全球首个开放 3T 级模型**
Moonshot AI 正式开源 Kimi K3，这是一个 2.8T 参数（104B 激活参数）的 MoE 模型，原生支持多模态与 100 万 token 上下文窗口。采用全新的 Kimi Delta Attention (KDA) + Attention Residuals 架构，配合 Stable LatentMoE（16/896 激活专家），训练效率较 K2 提升约 2.5 倍。支持长程编码、Agent 知识工作、多步推理等场景。权重已在 HuggingFace 和 ModelScope 开放。
🔗 https://github.com/MoonshotAI/Kimi-K3 | 📄 https://arxiv.org/abs/2607.24653

🚀 **LLM-Agent 长程规划研究新突破：Multi-Turn On-Policy Agentic Distillation**
提出一种多教师联合蒸馏框架，将单轮推理能力向多轮长程规划迁移。
🔗 https://arxiv.org/abs/2607.24720

🚀 **ELMOD：首个面向移动端推理的高效德语 2.7B 语言模型**
从数据到设备全栈优化，在移动设备上实现高效推理。
🔗 https://arxiv.org/abs/2607.24585

🔬 **D-Score：基于谱隐藏状态的 LLM 幻觉检测新方法**
利用隐藏状态谱信号检测 LLM 幻觉，无需外部知识库。
🔗 https://arxiv.org/abs/2607.24586

🔬 **PIVOT：面向 Token 级稀疏注意力的高效查询组索引**
针对长文本场景提出高效的稀疏注意力优化方案。
🔗 https://arxiv.org/abs/2607.24593

🏭 **SIREN：基于经验驱动的 LLM Agent 极端天气预警系统**
端到端的极端天气早期预警 Agent，将 LLM 与气象经验知识相结合。
🔗 https://arxiv.org/abs/2607.24588
