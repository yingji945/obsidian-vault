# 08-C 端用户旅程

> 📌 基于 V26.4.1 PRD 中的 15 个页面/流程整理（2026-07-29）
>
> 用户从扫码到完成核销的全流程体验设计

## 前置校验页（扫码前）

```
用户扫瓶内码
    │
    ▼
┌──────────────────────┐
│ ① 非微信环境提示页    │ ← 非微信打开时引导用微信扫描
│ （由易全提供）        │
└──────────────────────┘
    │
    ▼
┌──────────────────────┐
│ ② 扫码加载页 loading  │ ← 并行校验：活动时间/登录/设备风控/地址
└──────────────────────┘
    │
    ├── 活动未开始 → 弹窗"活动尚未开启，敬请期待"
    ├── 活动已结束 → 弹窗"活动已结束，下次再来哦"
    └── 校验通过 → 进入用户授权
```

## 用户授权流程

```
进入授权
    │
    ▼
┌──────────────────────┐
│ ③ 用户协议弹窗        │ ← "已阅读并同意《瑞幸咖啡用户协议》..."
├──────────────────────┤
│ [不同意]     [同意]   │ ← 不同意→无法参与，点击立即抽奖重新弹出
└──────────────────────┘
    │ 同意
    ▼
┌──────────────────────┐
│ ④ 微信手机号授权      │ ← 微信原生弹窗，展示脱敏手机号
│ 187****3732（上次提供）│
│ 182****2120           │
│ [使用其他号码]        │
└──────────────────────┘
    │ 授权
    ▼
┌──────────────────────┐
│ ⑤ 获取位置信息        │ ← 仅限配置了城市限定的活动
│ [允许]    [拒绝]      │
└──────────────────────┘
    │
    ▼
┌──────────────────────┐
│ ⑥ 易全返回码状态      │ ← 码状态=30（生产关联）才能参与
│   ├─ 有默认奖品 → 发给用户
│   └─ 无默认奖品 → "感谢品尝"
└──────────────────────┘
```

## 首扫中奖流程

```
码校验通过 → 进入抽奖
    │
    ├── 未中奖 → ⑦ "谢谢参与"弹窗
    │
    └── 中奖 → ⑧ 第一杯扫码结果页（中奖结果页）
                   │
            页面结构（3 区）：
            ┌─────────────────────┐
            │ ① 主视觉区          │ ← 深色背景，展示品牌形象
            │                     │   右上浮动按钮：我的奖品 / 活动规则
            ├─────────────────────┤
            │ ② 奖品呈现区        │ ← 浅灰背景，页面中央
            │                     │   展示膨胀效果大图 or 奖品大图
            ├─────────────────────┤
            │ ③ CTA 按钮区        │ ← 白色背景
            │   [领现金] [去膨胀]  │   支持 1 或 2 个按钮，适配多种状态
            └─────────────────────┘
          ┌─────────┴─────────┐
          ▼                   ▼
   ⑨ 领现金红包         ⑩ 去膨胀
          │                   │
          ▼                   ▼
  ⑪ 红包已领取页       ⑫ 膨胀成功弹窗
          │                   │
          ▼                   ▼
  提示"购买第2瓶后      ⑬ 膨胀结果页（展示膨胀后金额）
  扫码领现金"                 │
                              ▼
                        跳转商城下单
```

## 复购核销流程

```
用户购买第2瓶
    │
    ▼
扫描第2瓶瓶内码（校验流程同第1瓶）
    │
    ├── 现金红包路径
    │       │
    │       ▼
    │  ⑭ 现金到账页（"X元已存入微信零钱"）
    │
    └── 膨胀券路径
            │
            ▼
       ⑮ 我的券包抽屉（可在商城使用膨胀券下单）
            │
            ▼
      商城下单 → 使用膨胀券抵扣 → 订单确认收货
```

## 页面交互规范

文档中部分页面的交互细节：

| 页面 | 交互要点 |
|:----|:--------|
| **用户协议弹窗** | 不支持点击遮罩层关闭，必须通过按钮操作；不同意→停留当前页 |
| **手机号授权** | 微信原生弹窗（非小程序内），展示"上次提供"标记 |
| **扫码加载页** | 加载同时并行 5 项校验，省去串行等待 |
| **膨胀成功弹窗** | 弹窗后展示膨胀后金额 + 跳转商城按钮 |

## 需求演进中的体验取舍

| 版本 | 去掉/增加 | 原因推测 |
|:----|:---------|:--------|
| v1.2 | **去掉**地址授权必选 | 减少用户授权步骤，提升转化率 |
| v1.4 | **增加**单用户参与次数/日限制 | 风控兜底，防薅羊毛 |
| v1.5 | **增加**咖啡优惠券和库券 | 奖励类型扩展，不再限于现金红包 |
| v1.6 | **增加**加 C 获得方式 | 新增私域引流入口 |
