### 📄 重点论文
（arXiv 最新一批，2026-07-31 上架）

🤖 **LLM / 基础模型** — [Memory Decoder at Scale: A Pretrained, Parametric Long-Term Memory](https://arxiv.org/abs/2607.27919)
提出大规模预训练参数化长期记忆（Memory Decoder），为长上下文与记忆外置提供新思路。

🤖 **LLM / 推理** — [Sample More, Reflect Less: Self-Refine and Reflexion Lose to Repeated Sampling at Equal Token Cost](https://arxiv.org/abs/2607.28576)
在 1.5B~7B 规模上验证：同等 token 预算下，反复采样优于 Self-Refine/Reflexion 式自我反思，对推理时算力分配有直接指导意义。

🧠 **Agent / 工具** — [Qwen-UI-Agent Technical Report: Toward Next-Generation Real-World Centric Foundation GUI Agents](https://arxiv.org/abs/2607.28227)
通义千问 GUI Agent 技术报告，聚焦真实场景 GUI 智能体，与本周 OSReward、计算机操作 Agent 评测论文形成呼应。

🔒 **安全对齐** — [AISPA: User-Centric System Prompt Auditing for Large Language Model Applications](https://arxiv.org/abs/2607.28617)
面向 LLM 应用系统提示词的"用户视角"审计框架，为提示注入与提示词安全提供评测手段。

🔬 **AI for Science** — [PerturbMap: Cross-Context Transfer of Single-Cell Perturbation Responses](https://arxiv.org/abs/2607.28090)
