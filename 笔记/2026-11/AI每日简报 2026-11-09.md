### 📄 重点论文

- 🧠 **CPU-ARC: Agentic Reasoning Caching for on-CPU Reasoning Reuse** — 在 CPU 侧缓存并复用 Agent 的推理结果，直指 Agent 长链路重复推理的成本问题，对推理降本有直接参考价值。[arXiv](https://arxiv.org/abs/2611.09891)
- 🧠 **Ensemble Methodology for Reference-Free Confidence Estimation in LLM-based Code Summarization** — 没有标准答案时如何估计"模型有多确定"，用集成方法做无参考置信度，可用于给自动化产出加质量闸门。[arXiv](https://arxiv.org/abs/2611.09846)
- 🤖 **On the Reliability of Majority-Vote Pseudo-Labels in Test-Time Reinforcement Learning** — 检验测试时 RL 里"多数投票造伪标签"到底靠不靠谱，是对当前自我提升范式的一次压力测试。[arXiv](https://arxiv.org/abs/2611.09872)
- 🤖 **BitDecoding-FP4: Native FP4 KV Cache Decoding via Algorithm-System Co-Design** — 用 FP4 原生解码 KV Cache，算法与系统协同设计，属推理成本侧的硬优化。[arXiv](https://arxiv.org/abs/2611.09825)
- 👁️ **Flow-Guided Target-Space Alignment via Path Consistency** — 用路径一致性约束把生成过程对齐到目标空间，属生成模型训练方法，思路可迁移到图像/视频生成。[arXiv](https://arxiv.org/abs/2611.09863)
- 🔬 **Can Agentic Systems Close the Gap in Radiology with Production AI Tools?** — 在真实生产工具链下评估 Agent 能否补上影像科的缺口，是"Agent + 垂直行业"少见的严谨落地评估。[arXiv](https://arxiv.org/abs/2611.09836)

### 💡 小编建议

1. **Team Agent 值得你今天花 10 分钟实测**：千问办公 2.0 的"多人 + 多 Agent 协作"和你现在"脚本预抓取 + Agent 整理 + 人审"的流程同构，重点看它怎么处理**任务分派与冲突仲裁**——这正是多 Agent 落地真正的卡点，不是模型分数。
