## 码的体系

| 码类型 | 位置 | 用途 |
|:------|:-----|:-----|
| **瓶内码** | 瓶盖内部 | 活动参与入口，扫码抽奖 |
| **瓶盖外码** | 瓶盖外部 | 消费者溯源 + "欢迎扫瓶内码"引导 |
| **瓶身码** | 瓶身 | 活动规则说明入口 |

| **箱外码** | 包装箱外 | 物流追踪 |

## 红包权益状态机（完整版）

> 📌 基于 2026-07-29 文档补充：V26.4.1 技术方案中的 8 状态模型

### 状态总表

| 状态码 | 状态名称（英文） | 业务场景 | 关联数据 | 终态 |
|:-----|:---------------|:--------|:--------|:----|
| **10** | 待选择 (INIT) | 用户首扫中奖，尚未点击"领红包"或"去膨胀" | 首扫码 ID | ❌ |
| **20** | 待复购 (LOCKING) | 用户选择了现金，权益被锁定，等待购买第二瓶 | 首扫码、预生成权益 ID | ❌ |
| **30** | 待使用 (ACTIVE) | 用户选择了膨胀券，券已发至券包，可直接下单 | 商城优惠券 ID | ❌ |
| **40** | 打款中 (PAYING) | 用户完成复购扫码，系统正在请求微信支付接口 | 复购码 ID、微信商户单号 | ❌ |
| **50** | 已到账 (TRANSFERRED) | **【终态1】** 现金成功发放至用户微信零钱 | 微信支付流水号、打款时间 | ✅ |
| **60** | 已使用 (CONSUMED) | **【终态2】** 用户在商城下单并成功抵扣了膨胀券 | 商城订单号、父订单编号 | ✅ |
| **70** | 已过期 (EXPIRED) | 超过复购限时或商城券有效期 | — | ✅ |
| **80** | 已失效 (INVALIDATED) | 发生退货逆向、风控拦截或活动配置变更作废 | 失效原因说明 | ✅ |

### 关键区别说明

| 流转 | 旧版理解 | 实际（来自流程图） |
|:----|:--------|:---------------|
| **40→20** | 40→50 (支付成功) | ✅ 40→20 (支付失败可重试扫码) |
| **60→30** | 60→结束 (已使用) | ✅ 60→30 (取消订单但券有效，可再次使用) |
| **80 入口** | 仅从各状态逆向进入 | ✅ 10→80 (放弃或风控直接失效力) |
| **70 入口** | 各阶段超时 | ✅ 30→70 (超时未下单), 60→70 (取消且券已过期) |

## 码本身状态（易全侧）

> 📌 基于易全同步瓶内码接口文档补充（2026-07-29）

易全系统管理码的**物理生命周期**，从生产到出库共 4 个状态：

```
10 打码关联（码已生成→与产品关联）
  ↓
20 投料（原料投入生产）
  ↓
30 生产关联（码与批次关联）
  ↓
40 出库（产品进入流通）→ 可被用户扫码
```

| 状态码 | 名称 | 说明 |
|:-----|:----|:-----|
| **10** | 打码关联 | 瓶内码已生成并与产品 SKU 关联 |
| **20** | 投料 | 原料投入生产线 |
| **30** | 生产关联 | 瓶码与具体生产批次（lotno）关联 |
| **40** | 出库 | 产品出库进入流通渠道，用户可扫到该码 |

**注意：** 易全侧码物理状态（10~40）≠ 活动侧红包权益状态（10~80）
- 易全侧：管码的生产→出库
- 活动侧：管用户扫码→中奖→核销
- 两者通过 `productCode<b>→</b>扫描` 串联

### 数据同步机制

```
易全（码状态变更）
  │
  │  POST https://letp.lkcoffee.com/rtd/products/callback
  │  每批上限 100 条，TPS: 60
  │  鉴权：静态 key（双方约定）
  ▼
瑞幸侧（接收并更新码信息）
  │
  └── 保留查询接口用于一致性校验
```

## 关键校验

| 校验点 | 调用方 | 说明 |
|:------|:-------|:-----|
| 码有效性 | 易全五码系统 | 接口返回：有效/无效/已使用 |
| 码状态同步 | 电商促销系统→易全 | 用户扫码后异步同步状态 |

## 扫码场景

| 场景 | 触发方式 | 说明 |
|:----|:--------|:-----|
| **首扫码（活动）** | 瓶盖内码 | 用户首次发现并扫码参与活动 |
| **复购扫码** | 第二瓶瓶盖内码 | 已中奖用户购买第二瓶后扫码履约 |
| **规则扫码** | 瓶身码 | 用户扫码查看活动规则 |
| **溯源扫码** | 瓶盖外码 | 生产溯源信息 |
