# 易全同步瓶内码信息给瑞幸接口

> 📌 接口文档，2026-05-08 最后更新，蔡鸿东创建

## 接口概览

| 项目 | 内容 |
|:----|:----|
| **接口用途** | 易全营销瓶内码信息数据同步到瑞幸侧 |
| **调用时机** | ①初始数据批量导入 ②瓶内码状态变更时同步商品信息 |
| **接口 Path** | `POST https://letp.lkcoffee.com/rtd/products/callback` |
| **请求方式** | POST |
| **每批上限** | 100 条/批 |
| **TPS 限制** | 60（按箱分批） |
| **鉴权方式** | 静态 key（双方约定） |

## 入参

### 请求示例

```json
{
    "products": [
        {
            "productCode": "https://yiquantech.com/45d6f78weAkdiJKWE",
            "matName": "宏达特级清香型白酒500ml",
            "matNumber": "PRD-888-001",
            "lotno": "P20241121-001",
            "gatherTime": "2024-11-22 16:30:00",
            "status": 30,
            "shipDocsNum": "OUT20241123001",
            "deliveryTime": "2024-11-23 09:00:00",
            "dealerName": "上海宏达商贸有限公司",
            "dealerNumber": "DLR001234"
        }
    ]
}
```

### 参数详情

| 参数名 | 参数说明 | 类型 | 备注 |
|:------|:--------|:----|:----|
| productCode | 瓶内码 | string | 与请求体 barcode 等价 |
| matName | 产品名称 | string | 最大长度 128 |
| matNumber | 产品编码 | string | 最大长度 64 |
| lotno | 生产批号 | string | 最大长度 64 |
| gatherTime | 生产时间 | string | 格式 yyyy-MM-dd HH:mm:ss |
| status | 瓶内码状态 | integer | 10/20/30/40（见下方） |
| shipDocsNum | 出库单号 | string | 最大 64；未出库时为空 |
| deliveryTime | 出库时间 | string | 格式同上；未出库时为空 |
| dealerName | 经销商名称 | string | 最大 128；未出库时为空 |
| dealerNumber | 经销商编码 | string | 最大 64；未出库时为空 |

## 瓶内码状态枚举（易全侧）

| 状态值 | 状态名称 | 说明 |
|:-----|:--------|:----|
| **10** | 打码关联 | 瓶内码已生成并与产品关联 |
| **20** | 投料 | 原料投入生产 |
| **30** | 生产关联 | 瓶码与具体生产批次关联 |
| **40** | 出库 | 产品已出库进入流通 |

> ⚠️ 此状态是易全侧的**物理码生命周期**，对应码本身从生产到流通的流转，与用户在活动侧的红包权益状态机（10待选择~80已失效）是两套不同的体系。

## 返回说明

```json
{
    "code": "200"
}
```

| 返回码 | 含义 | 处理策略 |
|:------|:----|:--------|
| 200 | 处理成功 | — |
| 400 | 数据异常 | 排查原因（如字段超长）修复后重试 |
| 403 | 鉴权失败 | 检查 key |
| 429 | 超出频率限制 | 控制接口调用频率 |

> 非 200 应重试，但需区分错误类型：数据异常需排查修复后重试，频控则控制调用频率。
