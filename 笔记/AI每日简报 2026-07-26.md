## 📄 重点论文

### 🧠 Agent / 工具
- **AREX: Towards a Recursively Self-Improving Agent for Deep Research** — 提出递归自我改进的深度研究Agent，4B和122B MoE模型在BrowseComp、HLE等基准上大幅超越同规模基线。
  [arXiv:2607.21461](https://arxiv.org/abs/2607.21461)

- **OpenForgeRL: Train Harness-native Agents in Any Environment** — 开源框架实现基于harness的Agent端到端RL训练，GUI Agent在OSWorld达37.7，WebVoyager达72.3。
  [arXiv:2607.21557](https://arxiv.org/abs/2607.21557)

- **PATS: Policy-Aware Training Scaffolding for Agentic Reinforcement Learning** — 策略中心训练范式，将技能作为动态训练支架，在ALFWorld和WebShop上提升最高18.6%。
  [arXiv:2607.21419](https://arxiv.org/abs/2607.21419)

- **Agentic Context Management: Solving Agent Memory and Cost** — 将Agent记忆管理视为生命周期问题而非存储检索问题，提出五元原语架构，在LongMemEval达92%。
  [arXiv:2607.21503](https://arxiv.org/abs/2607.21503)

- **Euclid-MCP: A Model Context Protocol Server for Deterministic Logical Reasoning via Prolog** — 为LLM提供确定性逻辑推理的MCP服务器，在合规场景下杜绝幻觉。
  [arXiv:2607.21412](https://arxiv.org/abs/2607.21412)

- **PersonaTrail: Benchmarking Personalized Web Agents through Browsing Trails** — 基于真实浏览轨迹的个性化Web Agent基准，提出偏好感知上下文记忆架构。
  [arXiv:2607.20482](https://arxiv.org/abs/2607.20482)

### 🤖 LLM / 基础模型
- **Beyond Sycophancy: Structured Resistance and Compliance in LLM Moral Reasoning** — 从社会心理学三维度（距离、来源、联盟结构）研究LLM的道德判断修正过程。
  [arXiv:2607.21558](https://arxiv.org/abs/2607.21558)

- **MIRROR: Learning from the Other View for Multi-Modal Reasoning** — 多模态推理强化学习方法，通过视图间知识蒸馏提升VLM推理一致性。
  [arXiv:2607.21552](https://arxiv.org/abs/2607.21552)

- **The Active Ingredient in Muon's Grokking** — 分解Muon优化器加速grokking的机制，发现正交化是关键，谱归一化可安全移除。
  [arXiv:2607.20512](https://arxiv.org/abs/2607.20512)

### 🔒 安全对齐
- **Robust Critics: Defending LLMs Against Multi-Turn Attacks** — 多轮对话LLM安全防御框架，通过对话批评引导采样抵御逐步攻击。
