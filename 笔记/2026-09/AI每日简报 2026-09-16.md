### 📄 重点论文

🧠 **Agent / 工具** — [Agentic Societies Need a Social Harness](http://arxiv.org/abs/2609.17527v1)
提出多 Agent 社会需要「社会性约束框架」，而非只靠单体能力提升。为多 Agent 协作的失序问题给出制度化视角，是今日最值得读的一篇。

🔬 **AI for Science** — [ScienceBuddy: Recursive-in-Recursive Self-Improvement for Interactive Scientific Agents](http://arxiv.org/abs/2609.17523v1)
把递归自我改进嵌进科学交互 Agent，试图让科研 Agent 在迭代中自己变强。

👁️ **多模态** — [PhysStream: Streaming Physics-Grounded Video Generation with Structured Scene Memory and Fine-Grained Motion Control](http://arxiv.org/abs/2609.17521v1)
流式视频生成 + 结构化场景记忆 + 细粒度运动控制，直指长视频生成的物理一致性与可控性两大痛点。

🔒 **安全对齐** — [When Should LLMs Abstain? Chain-of-Self-Questioning for Selective Risk Control](http://arxiv.org/abs/2609.17516v1)
用「自我追问链」决定模型何时该拒答，把选择性风险控制做成可训练、可评估的机制。

👁️ **多模态** — [ENCP: Episode-Normalized Conformal Prediction for Vision-and-Language Navigation](http://arxiv.org/abs/2609.17499v1)
为 VLN 引入按 episode 归一化的保形预测，给导航决策加上带统计保证的不确定性度量。

👁️ **多模态** — [LACE: Layer-Wise Compression for Dynamic Frame Rate Codecs](http://arxiv.org/abs/2609.17509v1)
面向动态帧率编解码器的逐层压缩，属视频基础设施方向，对多模态数据的存储与传输入口有价值。

### 💡 小编建议

1. **今天两篇最值得花时间的是 `Social Harness` 和 `LACE`**：前者回答多 Agent 系统的失序治理，后者解决多模态数据的压缩成本，一个管「协作秩序」一个管「存储账单」，都属长期基础设施型工作，建议存入技能库并标好标签。
2. **今日 GitHub 榜单出现两个「周边工具」信号**（modelnap 管本地模型内存、is-gpt-nerfed 做能力退化检测）：说明本地跑模型的用户已规模化到需要工具链配套。如果你的工作流也重度依赖本地 LLM，值得把 modelnap 加进自启项，顺便参考 is-gpt-nerfed 的思路给自己的固定任务建一套回归对比。
